# Pipeline scripts (reference only, not run)

These are the original scripts 01 to 03 and `config.py` that produced `data/input/charging_demand_hexagons.gpkg`.
They are included to document the method. They read freight-flow files that are not redistributed
(see the main README) and contain the author's local paths, so they cannot run from this repository.
Reproduction in this repository starts from the per-hexagon demand in `data/input/`.
